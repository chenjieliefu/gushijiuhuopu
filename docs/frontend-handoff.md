## 运行与位置

- 技术栈：React + TypeScript + Vite；代码在 `frontend/`，分支 `feat/wangzexuan-frontend`。
- 开发 origin：`http://127.0.0.1:5178`。5173 已被本机其他项目占用，启动固定端口，冲突时报错。
- `cd frontend && npm ci && npm run dev`。生产静态目录由 `npm run build` 生成至 `frontend/dist/`。
- 默认 `VITE_TRANSPORT=mock`，本地模拟器不调用外部模型或后端。页面、帮助和章节状态明确标记为样例。
- 后续设置 `VITE_TRANSPORT=http` 和 `VITE_API_BASE_URL` 后重启 Vite；没有隐式回退到 mock。后端需允许上述精确 origin 的 CORS。

## 已交付的界面行为

- 营业/继续入口，店铺、看山、柜台相机和陈列位置；桌面左右布局，手机上下布局。
- 机身检查、两张照片切换、正反面翻转和放大；检查视图关闭后保留输入及聊天。
- 自由输入控件、建议问题、提示、等待反馈、异常重试；模拟回复仅覆盖少量固定意图，不作为真实 AI 的语义验收。
- 手记分别显示物件线索与看山讲述原话；不把玩家输入直接加入事实。
- 已解锁片段入口、分段阅读、阅读位置保存、重读；仅最后一段明确读完后标记已读，不因打开/关闭页面新增事实。
- 接收确认、保存成功后的告别/入架、跳过动效、收藏回顾、结束提示和二次确认重置。
- 刷新恢复存档与草稿；失败保留完整原始请求，刷新后仍能用同一请求重试。

## 与现有后端对齐的部分

`src/services/contract.ts` 对齐 State / Page / StoryMeta，并使用运行时 schema 验证。`http.ts` 的请求映射已通过 mocked-fetch 检查，并在 1440px 桌面 / 390px 手机浏览器中实际调用本地 FastAPI，走通会话、检查、聊天、读页、收藏、刷新恢复和重置。见 [本地联调记录](local-integration.md)。

| 返回字段/协议 | 前端行为 |
| --- | --- |
| 创建返回 token + state；其他写入直接返回 State | 分开解析，不重复追加本地消息 |
| `version` / `session_id` | 拒绝旧版本、异会话覆盖；旧幂等响应触发恢复最新状态 |
| `can_collect` | 决定接收入口，前端不根据聊天轮数判定 |
| `clues` / `messages` | 展示原值；不把 fact ID 或内部摘要冒充玩家线索 |
| `unlocked_pages` / `read_pages` | 分开显示；未读入口不强制弹窗，不中断输入 |
| `expression` | neutral / thoughtful / warm 可替换素材槽 |
| 写入 `request_id` / `expected_version` | 同一次失败重试保留 ID、版本和正文；等待期间锁住写操作 |
| 409 版本冲突 | 用户点击同步，再根据最新状态选择操作；不自动重放陈旧动作 |
| 401 无效会话 | 提供明确确认的重新开始入口；不因网络错误自动建会话 |
| 502 / 504 / 网络异常 | 保留状态、草稿和原始请求，提供重试；显示可用 trace_id |
| reset | 用户确认后请求；使用返回的递增版本，不在前端归零 |

存储键按 mock/http 和后端 origin 隔离。token 仅放浏览器存储/Authorization，不放 URL 或共享截图。`mock.ts` 的剧情、解锁和收藏逻辑只服务独立体验，不是生产规则引擎；真实模式依赖服务端返回。

## 仍需对齐，暂未实施

1. **正式故事配置**：当前 `sunny-day-preview` 是按产品文档整理的前端样例，后端目前是 `integration-demo` 的两条测试事实。ID、披露顺序与接收条件尚未统一。
2. **展示资源**：检查 target 到相机/照片素材的映射，照片数量、正反面关系、热点坐标；当前按已知测试 ID 做占位。
3. **故事页**：图片 URL、段落、页序和标题列表；当前接口只有 `id/title/text`，前端暂按空行切段，HTTP 目录使用通用标题。
4. **首次展示事实**：`/read` 只标记阅读；若需要图文页首次揭示真相，要扩展展示确认语义，不能由前端自行补事实。
5. **收藏来源**：author、original_url、adaptation_note、授权记录、已发现可选细节。现有文档未提供原作者/原文链接，界面明确待补，没有伪造链接。
6. **提示动作**：当前模拟器把“给我一点提示”作为样例聊天；真实后端要确认聊天意图还是独立接口。
7. **消息元数据**：当前只按顺序展示 role/text，无虚构时间戳；暂不强求 ID。如支持流式/编辑/增量恢复再定。
8. **共享环境联调**：本地测试服务已验证 CORS 和完整流程；仍需确认共享测试地址、正式模型等待时间与部署。此次未修改后端业务逻辑，未发布公网服务。
