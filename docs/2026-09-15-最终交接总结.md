```bash
cd frontend
npm ci
```

普通构建默认选择模拟服务，不能直接拿去覆盖正式站点。发布只包含后端、剧情、依赖和构建产物，密钥通过受控环境配置单独导入。禁止将本地完整工作目录、环境密钥或个人存档上传。
