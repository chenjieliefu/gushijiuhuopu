# 游戏声音素材

当前 `voices.json` 使用两套本机生成的参考配音，共 71 条 MP3：

| 角色 | 数量 | 参考录音 | 输出目录 |
| --- | --- | --- | --- |
| 剧情旁白 | 51 | 用户提供的听悟 02:13 记录 | `reference-voices-v1/narrator/` |
| 看山 | 20 | 用户提供的听悟 02:14 记录，清晰短句降噪版 | `kanshan-sunny-v2/` |

使用 Qwen3-TTS 1.7B Base 8bit / MLX Audio 0.5.4 在本机参考录音生成，逐句输出、统一响度。属于合成配音，并非将参考录音原句放进剧情。生成方法和验证说明见 `docs/reference-voice-production.md`。

两套声音按角色分别索引。旁白阅读及重听使用 narrator，看山交流及重听使用 kanshan。缺失配音时保留字幕，不自动混用角色或切换系统机械音。

`afternoon.wav` 为程序合成的 64 秒原创循环轻音乐。点击声音菜单可独立调整音乐和配音音量；配音播放时音乐自动降低。默认手动阅读，自动阅读为可选项。

旧的 sunny-voice 和 voice-*.wav 保留以便回退，当前清单不再引用。旧版语音生成脚本会覆盖清单，勿在新版部署流程中调用它。
