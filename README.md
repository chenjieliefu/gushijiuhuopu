# 故事旧货铺

以旧物为入口的互动叙事游戏。玩家检查物件、与看山自由交流、解锁图文故事，让旧物入店、故事入册。

## 核心流程

看山携物来访 → 观察与检查 → 自由追问 → 解锁故事片段 → 理解核心故事 → 接收寄展 → 旧物入店、故事入册。
